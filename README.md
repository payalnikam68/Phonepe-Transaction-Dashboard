# PhonePe Transaction Analysis Dashboard

## Project Overview
An interactive dashboard developed using Microsoft Excel to analyze PhonePe transaction data, identify payment trends, and present meaningful insights through data visualization.

## Tools Used
- Microsoft Excel

## Key Features
- Transaction amount and volume analysis
- State-wise transaction analysis
- Transaction category analysis
- Payment trends and pattern identification
- Interactive charts and visualizations

## Objective
To transform raw transaction data into meaningful insights using Excel-based data analysis and visualization techniques.
